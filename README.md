# The Everyday Table

A static recipe website for everydaytablekitchen.com. The published HTML, CSS, JavaScript, and image assets are in `public/`. Run `python generate.py` after editing recipe content; the generated pages preserve the eight food photos already in `public/`.

Vercel project settings: Framework Preset **Other**, Root Directory repository root, Output Directory **public**. Vercel redirects everydaytablekitchen.com to www.everydaytablekitchen.com. Set both A and CNAME records at Namecheap before using the domain publicly. The Contact page needs a real email address before AdSense review.
