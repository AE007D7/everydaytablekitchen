# The Everyday Table

A static recipe website for everydaytablekitchen.com. The published HTML, CSS, JavaScript, and image assets are in `public/`. Run `python generate.py` after editing recipe content; the generated pages preserve the eight food photos already in `public/`.

Vercel project settings: Framework Preset **Other**, Root Directory repository root, Output Directory **public**. Connect the custom domain in Vercel and set its DNS before using it publicly. The Contact page needs a real email address before AdSense review.
